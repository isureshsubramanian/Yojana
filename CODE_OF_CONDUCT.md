# Code of conduct

Yojana is a professional project. Everyone who takes part (in issues, pull requests, discussions or any other
project space) is expected to:

- be respectful and constructive, and assume good intent;
- critique ideas and code, never people;
- keep discussion on topic and free of harassment, discrimination, personal attacks and unwelcome attention;
- respect others' privacy: do not share anyone's personal or customer information.

Maintainers may edit or remove content, and may restrict or block participation, when this code is not followed.

To report a concern privately, use GitHub's private reporting on this repository (**Security → Report a
vulnerability**) and start the title with "Conduct:". Reports are read only by the maintainers and handled
confidentially.
