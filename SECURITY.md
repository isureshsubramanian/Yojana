# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the version or commit you tested. We aim to acknowledge a report
within five working days and will keep you informed until it is resolved. We are happy to credit you once a fix is
released, if you wish.

## Supported versions

Security fixes are made on `main`. There are no long-term support branches yet.

## Scope

In scope: the web host, the public API and webhooks, the customer portal, the relay and the render worker in this
repository. Out of scope: findings that need a compromised host or administrator account, and denial of service
by volume.
